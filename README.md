# SpendWise: Smart Expense Tracker and Budget Planner

Made by: Himanshu Negi
Subject: Web Programming
UID: 26MCA20134

A simple expense tracker built with HTML, CSS, and JavaScript.

## Features
- Add, edit, and delete expenses
- Filter by category and month
- Summary cards: total, this month, top category
- Pie chart of spending by category (Chart.js)
- Data saved in the browser with localStorage
- Dark mode
- Export to CSV

## How to run
Open `index.html` in any browser.

## Technologies
HTML, CSS, JavaScript, Chart.js
